# TECSUN PL-330 — Простая инструкция (PWA)

Офлайн-приложение с крупной пошаговой инструкцией к радиоприёмнику **Tecsun PL-330**
для пожилого пользователя: большие плитки-темы → понятные пронумерованные шаги.
Тёмная тема с янтарной «подсветкой дисплея», крупный текст, крупные кнопки.

**Живая версия:** https://makarych12.github.io/tecsun-pl330-guide/

## Что внутри

- Чистые HTML + CSS + vanilla JS, без фреймворков, CDN, трекеров и аналитики.
- PWA: `manifest.json` + `sw.js` (cache-first, версионированный кэш) —
  после первого открытия работает полностью без интернета.
- Устанавливается на главный экран Android и iOS (иконки 192/512/maskable,
  `apple-touch-icon`).
- Фото приёмника — Wikimedia Commons, лицензия CC0 (public domain).
- Анимации «эфира» на чистом CSS; полностью отключаются при
  `prefers-reduced-motion: reduce`.

```
/
├─ index.html
├─ manifest.json
├─ sw.js
├─ assets/        фото (webp + jpg), иконки
├─ css/styles.css
└─ js/
   ├─ topics.js   контент: категории и пошаговые темы
   ├─ extras.js   раздел «Интересное»: факты, круг суток, комплект, схема, викторина
   └─ app.js      меню, навигация, анимации, подсказка установки, регистрация SW
```

## Что нового в версии 2

**Контент** (по официальному руководству, стр. 2, 13, 16–17, 27–28, 31–38):
- Раздел **«Интересное»**: карточки «А вы знали?» (ETM vs ATS, тропические
  диапазоны, dBμ/SNR простыми словами, память на 650 станций и др.);
  **круг суток** — какие КВ-диапазоны пробовать утром/днём/вечером/ночью
  (по таблице принимаемости), с автоматическим выбором текущего времени;
  **что в коробке**; **что внутри приёмника** — собственная SVG-схема с
  подсветкой деталей (без чужих фото); **викторина** из 6 вопросов.
- Новые практические темы: набрать частоту цифрами, наушники и стерео,
  будильник любимой станцией (+ повтор через DISPLAY), расширение FM до 64 МГц.

**Анимации** (только CSS/SVG, всё выключается при `prefers-reduced-motion`):
- многослойные кольца эфира + «дыхание» подсветки и лёгкое мерцание LCD;
- направленные переходы между экранами (вперёд — справа, назад — слева),
  ступенчатое появление плиток, шагов и карточек;
- «утапливание» кнопок при нажатии, как на приёмнике;
- круг суток: плавный поворот стрелки, медленный «радарный» луч;
- викторина: мягкое свечение верного ответа, короткое покачивание неверного.

## Запуск локально

Нужен любой статический сервер (service worker работает на `localhost` и по HTTPS):

```bash
npx serve .
# или
python3 -m http.server 8000
```

Откройте http://localhost:8000/.

## Как установить на телефон

**Android (Chrome):** открыть ссылку → нажать «Установить» в подсказке внутри
приложения (или меню ⋮ → «Добавить на главный экран» / «Установить приложение»).

**iPhone (Safari):** открыть ссылку → кнопка «Поделиться» → «На экран «Домой»» → «Добавить».

## Обновление контента

Тексты тем — в `js/app.js` (массив `topics`). После любого изменения файлов
поднимите `VERSION` в `sw.js`, чтобы у пользователей обновился офлайн-кэш.
